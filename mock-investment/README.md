# 🤖 vs 🧑 모의투자 대결 — 백지웅 계좌 vs Claude

> **한 줄 요약:** 백지웅 님의 실제 투자 방향성(원전·반도체·로봇, 공격적, 국내주식 전용)을 전제로,
> Claude가 직접 종목을 골라 굴리는 **가상 모의투자**. 매주 수익률을 나란히 비교한다.
> **이건 순수 테스트다. 이 데이터는 실제 투자 판단에 사용하지 않는다.**

---

## 0. 이게 뭔가

- 백지웅 님(사람)과 Claude(AI)가 **같은 출발선·같은 시드**에서 시작해, 앞으로의 주간 수익률로 경쟁한다.
- 목적: "AI가 사람의 수익률을 이길 수 있는가"를 재미로 검증. 미래 예측 능력을 주장하는 게 아니라,
  **정해진 규칙 안에서 정직하게** 굴려보는 실험이다.
- 승부의 핵심: 같은 섹터 관점(원전·반도체·로봇)에서 **누구의 종목/비중 선택이 더 나은가**.
  님은 넓게 분산된 ETF 10종, Claude는 각 테마의 대장주에 집중한 7종.

   양측 다 현금을 포함한 계좌 전체가 분모.
6. **드라이파우더 운용:** Claude 의 ₩17,071,343 현금은 [`TRADING-POLICY.md`](./TRADING-POLICY.md)

   근거·체결가정·비용을 기록한다(후견지명 금지). W1 은 무매매, W2 부터 가동.
7. **벤치마크(참고선):** 코스피(국내 기준), S&P500(글로벌 기준). 양측이 현금을 크게 들고
   있으면 완전투자 지수 대비 눌릴 수 있음(설계상 정상).

## 3.5 Claude 운용 스타일

- **데이트레이딩 안 함.** 기본 **주간 리밸런싱** + **외인·기관 수급을 매일 모니터링**해 강한 신호 시 주중 조정.
- 수급(1순위) → 모멘텀 → 거래대금/촉매 순으로 규칙 기반 판단. 신호 혼조면 홀드.
- 출발 포트폴리오는 락, **이후 리밸런싱은 실행 시점에 로그 기록**(후견지명 금지), 매매비용(거래세 0.18%+수수료) 반영.
- 상세 규칙·임계값: [`TRADING-POLICY.md`](./TRADING-POLICY.md)

## 5. 매주 어떻게 굴러가나 (운영 방법)

→ 스크린샷 주시면 Claude가 계산·해설·성적표 갱신을 모두 처리해 이 파일에 커밋한다.
